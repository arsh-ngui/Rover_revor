# Rover_revor
Deployed on emergencies like mine explosions or collapse, meant to go places where humans physically cannot, controlled through a mesh network by dropping esp32 modules &amp; LoRa. equipped with Lidar and multiple sensors to measure gas levels, temp, humidity etc, and send a reading back to base camp

Frtizing- New files for sensors MQ& & MQ4 have been provided, which need to be installed within - to link these libraries a simple drag and drop to "my components" tab is required
